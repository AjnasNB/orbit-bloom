# Orbit Bloom release screenshots — build 6

Version 1.0, workspace build 6. [Thirty actual iPhone captures](build6/verification.json) and [nine iPad captures](build6/ipad/verification.json) come from passing native UI tests. The phone captures are 1320 × 2868, with seven iPad portraits at 2064 × 2752 and two landscape QA frames with original rotation metadata. No captures were resized or synthesized. **60 unique tests pass** across the recorded runs; live Apple cloud syncing remains a device check.

The ten build 6 iPhone files were selected for upload after moving the previous set into Apple's Asset Library. Their persisted/rendered state could not be verified before the Mac locked. Six older iPad portraits remain the last verified uploaded set. [Upload status](app-store-screenshots.json), [Apple status](app-store-status.json), [metadata](metadata.json) and [preparation notes](../APP_STORE_PREPARATION.md) track the remaining steps. Build 6 is signed/exported but not uploaded or submitted. The gallery below includes unchanged build 5 gameplay views; current captures and hashes are in build6/.
